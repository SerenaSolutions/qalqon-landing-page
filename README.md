# QALQON — The Gasoline Question

## Landing Page | International Edition | British English

An investigative landing page examining Brazil's shift in fuel composition from E30 to E32 ethanol blend. This project explores transparency in consumer information, pricing, and vehicle compatibility.

### Features

✓ **British English** — Optimised for international audiences (petrol vs gasoline, labelling vs labeling, etc.)  
✓ **LinkedIn Ready** — Full Open Graph meta tags, social card preview, and optimised sharing buttons  
✓ **Responsive Design** — Mobile-first approach with seamless desktop experience  
✓ **Dark Theme** — Professional, modern visual identity  
✓ **SEO Optimised** — Semantic HTML, meta descriptions, article schema  
✓ **Accessibility** — WCAG-compliant semantic structure  

### Conversion Updates

**Language (British English):**
- gasoline → petrol
- labeling → labelling
- color → colour
- August (date format adjusted to 1 August)
- Other BrE spellings and terminology

**LinkedIn Optimisation:**
- `og:` meta tags for rich preview
- `article:published_time`, `article:author`, `article:section`, `article:tag`
- Direct LinkedIn share URL with fallback
- WhatsApp share with pre-filled message
- Improved social card image meta

**International Standards:**
- `lang="en-GB"` attribute
- ISO date format (1 August 2026)
- International terminology across all content

### Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/SerenaSolutions/qalqon-landing-page.git
   cd qalqon-landing-page
   ```

2. Open `index.html` in your browser or serve it:
   ```bash
   # Using Python
   python -m http.server 8000
   
   # Using Node.js (http-server)
   npx http-server
   ```

3. Share on LinkedIn — the page includes optimised meta tags for preview rendering.
